# SMAPATISPA NEXORA

Aplikasi web **Bimbingan Konseling & Kesiswaan** SMA PGRI 43 Singaparna — untuk siswa, orang tua, Guru BK, Kesiswaan, wali kelas, guru piket, kepala sekolah, dan admin.

- **Tampilan:** HTML/CSS/JS murni (folder ini), di-host di GitHub Pages, bisa dipasang di layar utama HP (PWA).
- **Server:** Google Apps Script sebagai REST API + Google Sheets & Drive (berkas `.gs` disimpan terpisah, tidak di repository ini).
- **Satu-satunya pengaturan:** isi URL server di `js/config.js`.

Panduan lengkap pemasangan, akun contoh, dan pemecahan masalah: **[PANDUAN-INSTALASI.md](PANDUAN-INSTALASI.md)**.

Ikon: [Lucide](https://lucide.dev) (ISC). Huruf: Poppins, Inter, JetBrains Mono (Google Fonts).
